# neutron-navigator

travelers guide for navigating original ideas: a one-page reference for the **behringer neutron** paraphonic analog semi-modular synthesizer, software v1.2. the two 3340 oscillators, shapes switched or blended, sync and paraphonic, the 12 dB multi-mode filter and its second output, lfo and midi clock sync, envelopes, bbd delay, overdrive, sample and hold, slew, attenuators, every patch bay normal, the hold menus and patch ideas, with diagrams.

source: the behringer neutron user manual (software v1.2).

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with behringer / music tribe or mathias kettner.
